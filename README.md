# 유리스마 스트레칭 예약 (시안)

유리스마 스트레칭 1:1 패시브 스트레칭 예약 페이지의 **동작하는 시안**입니다. 유리스마스쿨 사이트 안으로 옮기기 위한 참고 자료예요.

**현재 버전: v23 (2026-11-08)** · 이전 버전은 [Releases](../../releases)에서 v22로 받을 수 있어요.

- 시안 주소: https://yurisma-stretching-booking.vercel.app (신규 `/`, 회원 `/?member`, 약정서 `/?contract`, 관리자 `/?admin`)
- 확정 요구사항: [`유리스마-스트레칭-예약-개발전달서.md`](./유리스마-스트레칭-예약-개발전달서.md) (마지막 장에 바이브 코딩용 요청문)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 전체(신규 예약, 회원 예약, 약정서, 관리자). 맨 위 `CONFIG`에 운영 설정 |
| `apps-script.gs` | 서버 로직(구글 시트 저장, 예약 규칙, 약정서, 가격, 구글 캘린더 연동). 실제 구현에서는 유리스마 DB로 대체 |
| `privacy.html` | 시안용 개인정보처리방침 |
| `약정서-원문.md` | 10·20회권 약정서 원문 |
| `유리스마-스트레칭-예약-개발전달서.md` | 확정 요구사항 |
| `DESIGN.md` | 유리스마스쿨 화면 기준(색·글꼴·버튼 모양) |
